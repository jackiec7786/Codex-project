# Spice Classifieds — Static Next.js UI

A coded, non-functional Next.js recreation of the provided Spice Classifieds desktop and mobile UI references.

## Included routes
- `/` — desktop hero + mobile splash/home compositions
- `/browse`
- `/listing/iphone`
- `/listing/apartment`
- `/dashboard`
- `/messages`
- `/saved`
- `/categories`
- `/services`
- `/post`
- `/profile`
- `/help`

## Run locally
```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Notes
- UI only: buttons, search, filters, chat, and listing actions are intentionally non-functional.
- The project uses cropped visuals from the reference images supplied in the conversation to preserve the look of the mockup.
- Mobile route screens are best previewed below 820px viewport width.
